# CareerLab AI — Phase 1

A free-first, low-cost AI career practice platform.

## Current Phase
This package contains the professional landing page and Phase 1 UI foundation.

### Included
- Responsive landing page
- Practice hub
- Real-world project concept
- AI mentor / interview concept
- ATS resume concept
- Competition concept
- Pricing UI
- Demo Login / Signup using localStorage
- Mobile responsive design

### Planned next phases
1. Supabase Auth + PostgreSQL
2. User Dashboard + Admin Panel
3. SQL Lab and question database
4. Real-world projects and datasets
5. ATS Resume Builder / Checker
6. AI Mentor + AI Mock Interview
7. English practice
8. Competitions + leaderboard
9. Jobs / recruiter / institute portals
10. Payments and monetization

## Run
Open `index.html` in a browser.

The demo authentication is intentionally local-only. Before production, replace it with Supabase Auth and secure backend/API functions.


## Updated preparation vision
The Job Ready Path is designed around realistic hiring preparation:
- role + company-type + experience selection
- aptitude and reasoning
- technical practice
- communication and English
- natural HR / technical mock interview
- adaptive follow-up questions
- real-world case studies
- daily preparation plans
- resume-based interview (planned)
- voice AI interview (planned)

Company references are treated as company-style preparation based on public role/interview information, not as claims of access to confidential interview questions.
